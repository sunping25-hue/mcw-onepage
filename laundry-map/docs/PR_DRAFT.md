## 變更

為 Issue #1 新增獨立 `laundry-map/` React / Express 專案，保留原有一頁式網站。包含 OSM 互動地圖／群聚／GPS／搜尋與收藏、門市詳情、YouTube 分類與外部入口、單一總部登入與 CRUD、SQLite migration、圖片驗證重編與持久儲存。

已依使用者提供地址，首次啟動建入屏東新園仙吉路 32 號與高雄三民大豐一路 26 號兩家門市；座標待確認時僅提供列表／地址導航，不建立虛構標記。首次建檔不覆蓋後台修改、不復活已刪除資料；未配置影片或連結明確禁用。公開機台狀態固定為未串接，提供 schema、TTL、受信任 API adapter 與受保護的 DEMO stub，不產生假即時空機資訊。

支援門市分享、直接網址、瀏覽器返回、照片手指滑動與 Google／Apple 導航選擇。街道圖磚失敗時提供 Natural Earth 公開授權臺灣向量輪廓及重試功能。

手機圖片使用自適應比例與完整照片檢視，驗收圖輸出為 375×812／390×844 手機視窗；教學與加盟等功能保留為地圖的次要入口。

另提供 SQLite 一致性線上備份、引用照片備份、登入工作階段移除及 SHA-256 清單，並附可直接依序操作的 Render 部署說明。
