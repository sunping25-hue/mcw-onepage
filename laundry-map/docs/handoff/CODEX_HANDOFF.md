# MCW 洗衣地圖｜Codex 開發交接規格 V1.0

## 目的與界線
建立可以從 **MCW LINE 官方帳號** 開啟、也能用手機瀏覽器直接存取的 **MCW 洗衣地圖**；設計視覺依照 `references/five-phone-original.jpg` 的五支手機介面，調成 **科技藍＋少量紅色點綴**，使用資料夾內真正的 MCW Logo、藍白貓咪吉祥物、花蓮門市照片與洗衣機照片。

**不開發**：獨立 iOS / Android App、QR 掃碼啟動、加盟主後台、AI 業務員、AI 智慧店長本體、支付與遠端控制洗衣機。AI 智慧店長僅預留一個可由總部後台設定的連結按鈕；「詢問加盟」只是表單或真人聯絡入口，非 AI 銷售機器人。

## 使用者端功能
1. 手機優先的 MCW 洗衣地圖，含縣市查詢、門市搜尋、GPS 最近門市、門市清單切換、收藏（可先以 localStorage 保存）。
2. 支援全台地圖縮放／標記叢集／點選標記與門市資訊卡。可以使用 Leaflet + OpenStreetMap（需保留地圖署名、注意正式流量下 tile provider 使用政策）；地圖資料來源可換成其他服務。地圖不可用整張圖片假裝互動。
3. 門市明細：實拍照片輪播、地址、電話（`tel:`）、營業時間、設備種類／型號／容量／數量、費率（不得猜測）、公告、 Google 評價、 Google Maps 與 Apple Maps 導航。
4. 「機台即時狀態」展示空閒／使用中／故障／離線／未知、剩餘時間、最後更新時間；設計 `MachineStatusProvider` 和預留 API adapter。**目前無真機串接**，正式頁面必須顯示「尚未串接設備，即時狀態暫不可用」，所有示範狀態須有醒目「模擬資料」標籤。不可造假空機數字或機台即時狀態。
5. YouTube「機台操作影片教學」按鈕；影片分類：洗脫烘、雙層烘、付款方式（先用待設定空狀態，不杜撰 YouTube 影片 ID）。
6. 「AI 智慧店長」連結按鈕：每家門市的 `aiManagerUrl` 後台可設定，空值顯示「即將開放」，不能假裝可以使用。連結如需傳 `store_id`，以明確白名單的 `storeId` 參數提供，勿將權限憑證寫在 URL。
7. 「詢問洗衣加盟」按鈕：開表單或總部指定真人聯絡管道，收集經同意的姓名、電話與地區，不自行開發 AI 業務員。
8. iPhone 和 Android 使用者點「導航」時可選 Google Maps／Apple 地圖；Apple Maps 使用 maps.apple.com，Google 使用官方 Maps URL。沒有指定商家座標時提示資料缺失。
9. 可透過 LINE 官方圖文選單開啟此站，日後串 LIFF；**未有 LINE LIFF ID 時先提供一般瀏覽器可用版本**，不要阻擋開發。

## 總部後台（只做這個後台）
1. 安全登入（正式環境需要後端 Auth，例如 Supabase Auth），僅總部帳號可編輯門市；多權限應在伺服器端與資料庫 enforce，不能只有前端隱藏。
2. 門市 CRUD：名稱、地址、坐標、電話、營業時間、圖片、開店狀態、公告、Google 評價網址、影片網址、AI 店長連結、加盟詢問方式。
3. 機台 CRUD：門市關聯、machineId、機號、設備類型、容量、型號、規格、數量、照片、價格與設備雲端 ID（可空）。
4. 設備狀態讀取 Provider 介面、資料新鮮度管理（stale TTL），預留原廠 HTTP API/MQTT/IoT 映射，無串接時狀態 = unknown。
5. 圖片上傳儲存在有權限管理的雲端儲存，前端不直接存第三方私密金鑰；總部修改後消費者頁面能立即或按快取規則更新。
6. 不需要加盟主帳號及後台，不需要客服工單管理（AI 店長已有獨立系統）。

## 真實門市與資料合規
- 真實素材來自 `assets/`，詳見 `asset-manifest.json`。素材為設計用，並不代表畫面上示例店面已核實地址。
- 花蓮旗艦店有照片與歷史概況（洗脫烘 8 台、雙層烘 3 台、加水站 3 支），但**地址、價格、電話、GPS 坐標未在此任務獲得完整驗證**，請留白在後台待總部確認。
- 不要把 178 家門市、空機數字、每家店地址等設計稿上的數字當真；只能顯示已發佈的真實 MCW 店家資料。若門市尚未建檔，顯示適當的空狀態。

## 視覺規格
- 參考圖：`references/five-phone-original.jpg`（五支手機展示、畫面層次、導覽／詳細頁、資訊卡）；`references/five-phone-tech-blue-red.jpg`（科技藍紅光版本）；品牌風格輔助參考 `references/mascot-brand-style.jpg`。
- 主色：深海軍藍 #071529、科技藍 #087CF4、電光青 #17CBFF，強調色紅 #ED2435、白 #FFFFFF；紅色僅作狀態、提醒、互動強調，不要整站紅色。
- 手機真實使用介面應與展示稿概念一致，但不是把整張廣告圖當作產品 UI。Web app 要可點擊、可搜尋、可導航、可更新。
- 品牌 Logo 以 `assets/mcw-logo-red.png` 和 `assets/mcw-round-logo.png` 為準；吉祥物 `assets/mcw-cat.webp`；門市與設備照片用 `assets/` 內素材。

## 第一版驗收條件
1. `npm install && npm run build` 成功，提供可測試網址或本地啟動指令。
2. 在 iPhone 寬度 375/390px 和桌面版完成響應式排版。
3. 地圖可實際互動，門市卡有照片、電話、導航、Google 評價、AI 店長與 YouTube 教學、加盟入口。
4. 可透過總部後台更新門市資料，更新會反映在顧客頁面；登入未授權者不可修改。
5. 實時設備 Provider stub 可經測試資料運作，未接原廠時明確顯示無即時資料。
6. 不會出現掃碼啟動、加盟主後台、AI 業務員、AI 店長重寫功能。
7. 提供 README、環境變數樣本、資料表 SQL/migrations、手動與自動驗收流程、正式部署所需缺少的憑證清單。
8. 不得覆蓋既有 `mcw-onepage` 網站；建立獨立 `laundry-map/` 專案或從獨立新 repo 開始，提交 PR 供驗收。
